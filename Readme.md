# 📸 Pixenture Labs

### Photography & Videography Service Website

**Developed by Sandesh Pate**

Pixenture Labs is a responsive photography and videography service website designed as a one-stop platform for customers to explore creative services, view service categories, communicate with the studio and submit booking requests through an attractive and user-friendly interface.

The project focuses on combining a modern visual design with interactive JavaScript functionality, responsive layouts, form validation and smooth user interaction.
